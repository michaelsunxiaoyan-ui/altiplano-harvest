# Altiplano Harvest

A responsive bilingual (English / Spanish) B2B supplier website for Bolivian Royal Quinoa and Chia Seeds.

## Pages

- Home
- About Us / Nosotros
- Products / Productos
- Quality / Calidad
- Packaging / Empaque
- Contact / Contacto

## Run locally

Requirements: Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
```

## Launch checklist

- Replace the demonstration email address with your commercial email.
- Connect the contact form to your email endpoint or CRM.
- Confirm all product specifications, certificates, pack formats and claims.
- Replace placeholder photography with licensed company/origin/product images if desired.
- Set the final production domain in the site metadata.

All external photography is loaded from Unsplash. The social sharing image in `public/og.png` is included locally.
